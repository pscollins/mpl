# RSSA IR Reading

This skill provides a framework for interpreting RSSA output files generated by the MLton/MPL compiler.

## Usage

When you encounter an RSSA file:
1.  **Reference the Cheat Sheet**: See [references/cheat-sheet.md](references/cheat-sheet.md) for syntax and structure.
2.  **Identify Components**: Look for `fun` definitions, `Label` blocks, and their `Kind`.
3.  **Trace Flow**: Use the `Transfer` section at the end of each block (Goto, Switch, Return, etc.) to understand the control flow graph.
4.  **Analyze Memory Access**: Pay attention to `Offset` (e.g., `OW64`, `OP`) and `SequenceOffset` (e.g., `XW8`) operands, which represent pointer arithmetic and heap access.

## Advanced Patterns

- **Parallelism (MPL)**: Look for `Spork` and `Spoin` transfers and `SporkSpwn`/`SpoinSync` block kinds. These represent the spawn/sync points in parallel code.
- **Heap Operations**: `NormalObject` statements indicate allocation. `Offset` operands indicate field access.
- **C Calls**: `CCall` transfers handle interaction with the runtime system (e.g., `GC_collect`, `GC_sequenceAllocate`).
